# Half-Page Reflection: Steering the AI Agent in the Salon Queue Management Project

### 1. One Thing the Agent Got Wrong
During the initial project bootstrap and documentation phase (Prompts 1 & 2), the AI agent misinterpreted the project's architectural structure and scope. Instead of architecting a clean, modular separation between the client and server layers, the agent initialized a monolithic application directly at the repository root. Concurrently, it over-engineered a bilingual localization engine (English and Gujarati dictionaries with a React Context switcher) and applied a generic, off-the-shelf charcoal and yellow Tailwind color scheme that lacked the bespoke, high-end aesthetic demanded for a luxury salon.

### 2. How I Noticed It
I identified this issue during the initial code review and multi-tab test run. First, browsing the project tree revealed root-level clutter: Vite configuration files, React source directories, and frontend dependencies occupied the top level alongside backend files, which would complicate containerization, deployment, and independent server scaling. Second, upon previewing the UI, the interface felt like a standard dark-mode dashboard rather than an upscale salon experience, and the redundant bilingual switcher introduced state complexity and translation key lookup overhead across the seven target screens without delivering real business value.

### 3. How I Fixed the Prompt and Documentation
To resolve this, I intervened immediately by refining both my follow-up prompt (Prompt 3 in `prompts.md`) and the project guidelines in `AGENTS.md`:
- **Explicit Folder Classification**: I issued a direct structural constraint: *"classify frontend in a separate frontend directory and backend in backend one"*, forcing the agent to cleanly decouple the Vite/React application from the backend synchronization service.
- **Strict Scope Narrowing (Language)**: I eliminated the bilingual requirement with an explicit directive: *"the website should solely be in english"*, instructing the agent to deprecate the Gujarati dictionary (`gu.json`) and strip out translation context overhead in favor of clean, direct typography.
- **Design Directive Replacement**: I explicitly flagged that *"the color theme is very generic, try something different"*, steering the agent toward a distinctive **Velvet Obsidian & Champagne Rose Gold** palette (`#08090C` canvas, `#161922` smoked glass cards, and `#E5C392` champagne accents) paired with Web Audio API synthesized chimes.
- **Execution & Commit Cadence**: I added a procedural rule: *"keep committing after every small change, I need more commits"*, ensuring atomic git commits and clear verification checkpoints after every screen.

This prompt adjustment transformed a generic, cluttered codebase into an organized, production-grade monorepo with an elegant, cohesive user experience and robust deterministic queue synchronization.
